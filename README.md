# SABAR
---
SABAR (Sistem Antrean Bimbingan dan Arsip Revisi) merupakan aplikasi berbasis website yang membantu mahasiswa dan dosen mengelola proses bimbingan skripsi secara terstruktur. Mahasiswa dapat melihat jadwal dan kuota bimbingan, mengambil nomor antrean, memantau status serta estimasi waktu tunggu, dan mengunggah berkas revisi. Dosen dapat mengatur jadwal, mengelola antrean, serta memberikan catatan hasil bimbingan.

SABAR juga menyediakan riwayat bimbingan, notifikasi dalam aplikasi, serta pengelolaan akun oleh admin dengan hak akses sesuai peran. Proyek ini bertujuan mengurangi ketidakpastian antrean dan memusatkan catatan serta berkas revisi agar proses bimbingan lebih mudah dipantau.
